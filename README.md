# KET / PET / FCE Reading and Listening HTML Quiz

Interactive Cambridge reading practice board with:

- PET Reading Tests 1-4 (Parts 1-6)
- FCE Reading Tests 1-4 (Parts 1-3)
- Cambridge English First for Schools 3, Tests 1-4 (Reading Parts 5-7)
- A2 Key (KET) Listening Tests 4-8 (Parts 1-5, Questions 1-25)
- B1 Preliminary (PET) for Schools Listening Tests 13-17 (Parts 1-4, Questions 1-25)
- B2 First (FCE) Listening Tests 51-67 (Parts 1-4, Questions 1-30)
- Embedded original listening video with part and question time links
- Question-aligned answer evidence and study notes
- Original source-page scans beside interactive answer controls
- Immediate feedback and saved progress
- Clickable vocabulary with Traditional Chinese meanings
- A per-test vocabulary review list stored in the browser

Open the published site through GitHub Pages or serve this folder with any static web server.

Direct links: `#ket-listening`, `#pet-listening`, `#fce-listening`, `#fce-reading` and `#pet-reading` open the board at that section.
